# Security Policy

## Supported Versions

| Version | Supported          |
| ------- | ------------------ |
| 2.1.x   | :white_check_mark: |
| < 2.1   | :x:                |

## Reporting a Vulnerability

If you discover a security vulnerability, please report it by opening an issue
with the label "security" or by emailing the maintainer directly.

We will acknowledge receipt within 48 hours and provide a timeline for a fix.
Please do not disclose the vulnerability publicly until we have addressed it.
