I want to understand the all-MiniLM-L6-v2 sentence embedding model in depth
for an academic paper. Cover:

1. Knowledge Distillation: How MiniLM distills BERT-base (110M params) down

2. Contrastive Learning: How the model was trained with 1B+ sentence pairs

4. Technical Details: Transformer architecture with 6 encoder layers, 4
   attention heads per layer, hidden size 384, feed-forward 1536. Total

6. Cosine Similarity Math: Formula cos(θ) = (A·B)/(||A||×||B||). Why it ranges

7. HNSW (Hierarchical Navigable Small World): How vector indexes work for
   approximate nearest neighbor search. Multi-layer graph structure. Parameters:
   M (connections per node), ef_construction (build quality), ef_search (search
   depth). Complexity O(log n) vs O(n) brute force. How ChromaDB implements it
   internally.

8. Weight-Bleeding Technique (our innovation): How we simulate term weighting
   in embedding space by repeating high-weight terms proportionally in the
   reference text before embedding. Example: weight=5.0 → term repeated 5× in
   reference text. This shifts the reference embedding centroid toward high-weight
   terms. Paper/reference on this technique if it exists.

9. Comparison with alternatives: How all-MiniLM-L6-v2 compares against:
   - BERT-base (110M params, 768 dims) — why we chose smaller
   - SBERT (Sentence-BERT) variants
   - Instructor-XL (large embedding models)
   - OpenAI text-embedding-3-small/large
   - E5, BGE, GTE models
   - Key tradeoffs: size vs quality, CPU vs GPU, open vs closed

10. Academic Applications: How sentence embeddings are used in systematic

================================================================================
 DIFERENCIAL: WEIGHT-BLEEDING TECHNIQUE
================================================================================

Para simular pesos nos embeddings (já que embeddings não aceitam pesos
diretamente), repetimos termos de alto peso proporcionalmente:

    Exemplo: "atomic settlement" com weight=5.0
    → aparece 5× no texto de referência antes de embeddar

Isso faz o embedding "pender" semanticamente para termos mais importantes.
Não encontramos literatura formal sobre esta técnica — pode ser original.
